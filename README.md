# Spanish Tutor

Personalized, listening-first Spanish learning program targeting everyday northern Mexican Spanish, especially Monterrey. The repository is the durable source of truth for goals, lessons, assessments, vocabulary and session progress.

## Start here
1. Read `AGENTS.md` and `learner/profile.md`.
2. Review `docs/curriculum.md` and `docs/tutoring-methodology.md`.
3. Conduct a gentle baseline assessment; record results without assuming a CEFR level.
4. After each lesson update the journal and vocabulary review data.

**Status:** Initial design, not yet an implemented tutoring application. Voice and audio availability depend on the ChatGPT session and connected tools.
